# Guide Rapide des Endpoints REST

- `POST /api/v1/auth/login` : Authentification JWT.
- `GET /api/v1/vehicles` : Liste et recherche de véhicules.
- `POST /api/v1/bookings` : Création de réservation avec vérification de disponibilité.
- `GET /api/v1/vehicles/dashboard` : Alertes maintenance urgentes.
